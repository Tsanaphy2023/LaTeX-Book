## 3. สถาปัตยกรรมระบบการติดตามวัตถุและปฏิสัมพันธ์ (Multi-Modal Tracking Technologies)

ระบบรองรับการเชื่อมโยงระหว่างโลกทางกายภาพ (หนังสือเล่มพิมพ์) และโลกเสมือนจริง 3 มิติ ผ่านกลไกการติดตาม 3 รูปแบบ:

```
                                  [ กล้องสมาร์ทโฟน / เว็บแคม ]
                                                │
                 ┌──────────────────────────────┼──────────────────────────────┐
                 ▼                              ▼                              ▼
    [ 1. 2D Image Tracking ]        [ 2. Touchless Hand AI ]       [ 3. Markerless SLAM ]
    (ตรวจจับแผนภาพในหนังสือ)         (ตรวจจับ 21 ข้อต่อนิ้วมือ)        (วางเครื่องทดลองบนโต๊ะจริง)
  - MindAR.js (Compiled Feature)  - MediaPipe Hands Wasm Pipe    - WebXR Hit Test API
  - ARCore Augmented Images       - Pinch Detection (dx^2+dy^2)  - ARCore / ARKit Plane Detect
  - ARKit Reference Image Library - 60 FPS Low Latency Pipeline  - สเกลวัตถุจริง 1:1
```

### 3.1 การติดตามภาพเป้าหมายในเล่ม (2D Natural Feature Image Tracking)
* **กลไก**: เมื่อผู้เรียนเปิดกล้องส่องไปที่แผนภาพทางเทคนิคในหนังสือ (AR Marker Target เช่น รูปเครื่องมือสลิตคู่, วงจรชอร์ หรือชิป Transmon) ระบบจะคำนวณระนาบและมุมมองกล้อง (Pose Estimation) เพื่อเรนเดอร์โมเดล 3D แบบแอนิเมชันให้ลอยตรึงติดแน่นอยู่บนหน้ากระดาษเสมือนวัตถุจริง
* **โหมดออนไลน์**: ใช้เทคโนโลยี **MindAR.js** (WebAssembly + WebGL) แปลงภาพในเล่มเป็นไฟล์คุณลักษณะเฉพาะ `.mind` ที่มีขนาดไฟล์เล็กมาก (ต่ำกว่า 50 KB ต่อภาพ) โหลดผ่านเครือข่ายได้ทันทีโดยไม่กระตุก
* **โหมดออฟไลน์**: ใช้ **ARCore Augmented Image Database (Android)** และ **ARKit Image Asset Catalog (iOS)** คอมไพล์เก็บไว้ในเครื่องแบบเนทีฟ รันตรวจจับได้ทันทีแม้อยู่ในโหมดเครื่องบิน (Airplane Mode)

### 3.2 การควบคุมไร้สัมผัสด้วยปัญญาประดิษฐ์ (Touchless AI Hand Gesture Control)
* **กลไก**: ขจัดข้อจำกัดของการแตะหน้าจอมือถือขณะส่องกล้อง ผู้เรียนสามารถวางสมาร์ทโฟนตั้งไว้ แล้วใช้มือข้างว่างยกขึ้นมาหน้ากล้องเพื่อสั่งการ
* **สถาปัตยกรรม MediaPipe Hands**:
  * สกัดพิกัด 3 มิติของ 21 Joint Keypoints ต่อเฟรม
  * ตรวจจับการจีบนิ้ว (**Pinch Gesture**: ปลายนิ้วโป้งและนิ้วชี้เข้าใกล้กันต่ำกว่าระยะ Threshold) เพื่อจับยึด (Grab), หมุน (Rotate 3D), หรือเลื่อนแถบพลังงาน
  * การแบมือ/ชูนิ้วชี้ เพื่อสลับโหมดการทดลอง เช่น เปิด-ปิดผู้ดักฟัง Eve หรือเปลี่ยนสถานะจาก $1s$ เป็น $2p_z$

### 3.3 การวางจำลองบนพื้นผิวโลกจริง (Markerless SLAM Tracking)
* รองรับมาตรฐาน **WebXR Device API (Hit Test)** และ **ARCore Plane Detection** ช่วยให้ผู้เรียนสามารถนำอุปกรณ์ห้องปฏิบัติการควอนตัมขนาดใหญ่ (เช่น ตู้ทำความเย็น Dilution Refrigerator) มาวางบนโต๊ะหรือพื้นห้องเรียนขนาดเท่าของจริง (1:1 Scale) เพื่อเดินสำรวจโครงสร้างภายในได้แบบ 6-DoF

## 4. กลไกการแสดงผล 3D Animation และสังเคราะห์เสียงอะคูสติกตามหลักฟิสิกส์

### 4.1 PBR Shaders & Dynamic Volumetric Lighting
* ใช้วัสดุแบบ Physically Based Rendering (PBR) จำลองคุณสมบัติทางแสงของวัสดุในห้องปฏิบัติการ:
  * **Brushed Aluminum**: โครงสร้างแท่นออปติกและโครงกล้อง STM
  * **Gold-Plated Ceramics**: ขาพินของชิปควอนตัมประมวลผล Transmon
  * **Emissive Halos & Laser Beams**: ลำแสงเลเซอร์ที่มีการเรืองแสงเชิงปริมาตร (Volumetric Bloom)
  * **Glass Dispersion**: ปริซึมและอุปกรณ์แยกโฟตอน (Beam Splitter) ที่แสดงการหักเหแสงตามความยาวคลื่น

### 4.2 Web Audio API Real-time Acoustic Synthesizer (Zero-Byte Audio Architecture)
* ปัญหาดั้งเดิมของแอปจำลองการศึกษาคือการต้องโหลดไฟล์เสียง `.mp3` หรือ `.wav` จำนวนมาก ซึ่งสิ้นเปลืองแบนด์วิดท์และทำให้แอปโหลดช้า
* **แนวทางแก้ไข**: ใช้ **Web Audio API** สร้างวงจรออสซิลเลเตอร์สังเคราะห์เสียงขึ้นมาแบบเรียลไทม์จากสมการคณิตศาสตร์:
  * *เสียงคลิกไมโครมิเตอร์*: คลื่นเสียง Impulsive Damped Sine 1200 Hz สั้น 20 ms
  * *เสียงฮัมของเลเซอร์ควอนตัม*: คลื่นฟันเลื่อยความถี่ต่ำ (Low-pass Filtered Sawtooth 110 Hz)
  * *เสียงเตือนการดักฟัง (Eavesdropping Alert)*: คลื่นไซน์สองความถี่สลับก้อง 880/440 Hz
  * **ข้อได้เปรียบ**: ขนาดไฟล์เสียงเป็น **0 ไบต์** ทำงานทันทีโดยไม่มีอาการดีเลย์ของบัฟเฟอร์

### 4.3 Zero-GC High-Performance Animation Loop
* วัตถุทางคณิตศาสตร์ทั้งหมด (`THREE.Vector3`, `THREE.Matrix4`, `THREE.Quaternion`) ถูกประกาศไว้ภายนอกฟังก์ชัน `requestAnimationFrame` (Pre-allocated Object Pooling)
* ป้องกันไม่ให้ JavaScript Garbage Collector ทำงานคั่นจังหวะการเรนเดอร์ รักษาความเสถียรของเฟรมเรตที่ **60 FPS** บนสมาร์ทโฟนทุกระดับ

## 5. การทำงานแบบ Dual-Mode (Online Web App vs Offline Mobile App)

| มิติการทำงาน | โหมดออนไลน์: Progressive Web App (PWA) | โหมดออฟไลน์: Cross-Platform Mobile App |
| :--- | :--- | :--- |
| **สถาปัตยกรรม** | HTML5 / Vanilla CSS / ES6 Modules / Three.js | Flutter Framework / Dart / ARCore & ARKit Plugin |
| **การเข้าถึงของผู้เรียน** | สแกน QR Code จากหนังสือ เปิดผ่าน Safari/Chrome ทันที | ติดตั้งผ่าน APK / Google Play / Apple App Store ครั้งเดียว |
| **การจัดเก็บข้อมูลแคช** | **Service Workers (Cache-First)** บันทึกไฟล์ไว้ใน IndexedDB/CacheStorage | **100% Embedded Local Assets** โมเดล 3D และโค้ดอยู่ใน Bundle ของแอป |
| **การเชื่อมต่ออินเทอร์เน็ต** | ใช้อินเทอร์เน็ตในการเปิดครั้งแรก หลังจากนั้นเปิดออฟไลน์ได้ | **ไม่ต้องใช้อินเทอร์เน็ตเลย** ใช้งานบนเรือ กลางป่า หรือห้องใต้ดินได้ |
| **การประมวลผลโค้ด** | Python In-Browser ผ่าน WebAssembly (Pyodide) | Pure Dart Quantum Computation Engine |
| **ขนาดพื้นที่จัดเก็บ** | เบามาก (ไม่เปลืองพื้นที่อุปกรณ์) | ประมาณ 70–95 MB (รวม Asset 3D ทั้งหมด) |
