\chapter{สูตรอาหารเลี้ยงเชื้อมาตรฐานสำหรับจุลินทรีย์การเกษตร}
\label{app:media_recipes}

อาหารเลี้ยงเชื้อสังเคราะห์ในห้องปฏิบัติการทางจุลชีววิทยาการเกษตร มีความสำคัญอย่างยิ่งในการแยกเชื้อ การเพิ่มปริมาณ และการทดสอบกิจกรรมทางชีวเคมี สูตรอาหารมาตรฐานที่นิยมใช้แพร่หลายมีดังนี้:

\section{อาหารเลี้ยงเชื้อแบคทีเรียทั่วไป (Nutrient Agar: NA)}
\begin{itemize}
    \item สารสกัดจากเนื้อ (Beef extract) \dotfill 3.0 กรัม
    \item เปปโทน (Peptone) \dotfill 5.0 กรัม
    \item วุ้น (Agar) \dotfill 15.0 กรัม
    \item น้ำกลั่น (Distilled water) \dotfill 1,000 มิลลิลิตร
    \item ปรับค่า pH ให้อยู่ในช่วง 6.8 $\pm$ 0.2 ที่อุณหภูมิ 25 องศาเซลเซียส
\end{itemize}

\section{อาหารเลี้ยงเชื้อรา (Potato Dextrose Agar: PDA)}
\begin{itemize}
    \item มันฝรั่งปอกเปลือกหั่นเต๋า (Infusion from potatoes) \dotfill 200.0 กรัม
    \item เด็กซ์โทรส (Dextrose) \dotfill 20.0 กรัม
    \item วุ้น (Agar) \dotfill 18.0 กรัม
    \item น้ำกลั่น (Distilled water) \dotfill 1,000 มิลลิลิตร
    \item ปรับค่า pH ให้อยู่ในช่วง 5.6 $\pm$ 0.2
\end{itemize}

\section{อาหารทดสอบการละลายฟอสเฟต (Pikovskaya's Agar)}
ใช้สำหรับคัดแยกจุลินทรีย์ละลายฟอสเฟต (PSM) โดยสังเกตการเกิดวงใส (Clear Zone) รอบโคโลนี:
\begin{itemize}
    \item กลูโคส (Glucose) \dotfill 10.0 กรัม
    \item แคลเซียมฟอสเฟต ($Ca_3(PO_4)_2$) \dotfill 5.0 กรัม
    \item แอมโมเนียมซัลเฟต ($(NH_4)_2SO_4$) \dotfill 0.5 กรัม
    \item โพแทสเซียมคลอไรด์ ($KCl$) \dotfill 0.2 กรัม
    \item แมกนีเซียมซัลเฟต ($MgSO_4 \cdot 7H_2O$) \dotfill 0.1 กรัม
    \item แมงกานีสซัลเฟต ($MnSO_4 \cdot H_2O$) \dotfill 0.002 กรัม
    \item เฟอรัสซัลเฟต ($FeSO_4 \cdot 7H_2O$) \dotfill 0.002 กรัม
    \item สารสกัดจากยีสต์ (Yeast extract) \dotfill 0.5 กรัม
    \item วุ้น (Agar) \dotfill 15.0 กรัม
    \item น้ำกลั่น (Distilled water) \dotfill 1,000 มิลลิลิตร (pH 7.0 $\pm$ 0.2)
\end{itemize}

\section{อาหารเลี้ยงแบคทีเรียตรึงไนโตรเจนพืชตระกูลถั่ว (YEMA)}
Yeast Extract Mannitol Agar (YEMA) สำหรับเลี้ยงเชื้อ \textit{Rhizobium} และ \textit{Bradyrhizobium}:
\begin{itemize}
    \item แมนนิทอล (Mannitol) \dotfill 10.0 กรัม
    \item ไดโพแทสเซียมไฮโดรเจนฟอสเฟต ($K_2HPO_4$) \dotfill 0.5 กรัม
    \item แมกนีเซียมซัลเฟต ($MgSO_4 \cdot 7H_2O$) \dotfill 0.2 กรัม
    \item โซเดียมคลอไรด์ ($NaCl$) \dotfill 0.1 กรัม
    \item สารสกัดจากยีสต์ (Yeast extract) \dotfill 0.5 กรัม
    \item วุ้น (Agar) \dotfill 15.0 กรัม
    \item สีคองโกเรด (Congo red, 0.25\%) \dotfill 10 มิลลิลิตร (สำหรับแยกความแตกต่าง)
    \item น้ำกลั่น (Distilled water) \dotfill 1,000 มิลลิลิตร (pH 6.8 $\pm$ 0.2)
\end{itemize}
