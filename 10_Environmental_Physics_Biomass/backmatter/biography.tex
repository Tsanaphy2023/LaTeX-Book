\noindent\textbf{ผู้ช่วยศาสตราจารย์ ดร.ชีวะ ทัศนา}
\begin{itemize}
    \item \textbf{ตำแหน่งปัจจุบัน:} ผู้ช่วยศาสตราจารย์ สาขาวิชาฟิสิกส์ คณะวิทยาศาสตร์และเทคโนโลยี มหาวิทยาลัยราชภัฏรำไพพรรณี
    \item \textbf{คุณวุฒิการศึกษา:}
    \begin{itemize}
        \item ปรัชญาดุษฎีบัณฑิต (ปร.ด.) สาขาฟิสิกส์ประยุกต์
        \item วิทยาศาสตรมหาบัณฑิต (วท.ม.) สาขาฟิสิกส์
        \item วิทยาศาสตรบัณฑิต (วท.บ.) สาขาฟิสิกส์
    \end{itemize}
    \item \textbf{ความเชี่ยวชาญและผลงานเด่น:}
    \begin{itemize}
        \item ผู้เชี่ยวชาญการประเมินคาร์บอนเครดิต T-VER ด้านพลังงานและป่าไม้การเกษตร
        \item หัวหน้าโครงการวิจัยพัฒนาถ่านอัดแท่งเสริมประสิทธิภาพความร้อนด้วยคาร์บอนแบล็ค
        \item ผู้วิจัยและพัฒนาโมเดลปัญญาประดิษฐ์เพื่อการประเมินมลพิษฝุ่น PM2.5 จากภาพถ่ายสมาร์ทโฟน
    \end{itemize}
\end{itemize}
